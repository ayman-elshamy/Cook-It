# 🍳 CookIt

CookIt is a modern Android application for discovering meals and exploring different food categories.

The application provides a clean and simple user experience where users can browse food categories and explore the meals available in each category.

---

## ✨ Features

- 📂 Browse different meal categories
- 🍽️ Explore meals based on the selected category
- 🖼️ Display meal images and information

---

## 🛠️ Tech Stack

### Language
- Kotlin

### UI
- Jetpack Compose

### Networking
- Retrofit

### Image Loading
- Coil

### API
- TheMealDB
